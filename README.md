# Kuro Suite

Kuro Suite est une plateforme open-source unifiée de services cloud et collaboratifs comprenant :

- **Abraham AI** (Rebranded Open WebUI / BitNet)
- **Kuro PDF** (Rebranded Stirling-PDF)
- **Kuro Send** (Rebranded LocalSend)
- **Kuro Diagram** (Rebranded Draw.io)
- **Kuro Drive** (Nextcloud)
- **Kuro Chat** (Mattermost)
- **Kuro Meet** (Jitsi Meet)
- **Kuro Mail** (Stalwart Mail)
- **Kuro CRM** (Twenty CRM)
- **Kuro Data** (Baserow)
- **KuroWatch** (Changedetection)
- **Kuro Apps** (Budibase)
- **Kuro Studio** (Shotcut)

## Structure des répertoires

- `/upstream/` : Ensemble des dépôts et sous-modules d'outils open-source réalignés avec la marque Kuro.
- `/rebrand dossier logo kuro/` : Visuels, favicons et logos officiels au format PNG.
- `rebrand.js` : Script de rebranding réutilisable (substitutions de marque, assets et thèmes CSS sombres).
