Questions Fréquentes

Technique, Déploiement et Business.

Comment se passent les sauvegardes (Backups) ?
L'architecture Kuro repose sur un stockage objet S3/R2 distant. Les bases de données sont sauvegardées quotidiennement via des snapshots chiffrés sur le VPS, et les fichiers lourds bénéficient de la redondance native du stockage objet choisi.
Est-ce compatible avec nos logiciels existants (Word, Excel...) ?
Oui. Kuro Suite intègre nativement une suite bureautique Web compatible avec les formats Microsoft Office (.docx, .xlsx, .pptx). Vous pouvez éditer ces fichiers à plusieurs en temps réel directement depuis votre navigateur.
Que se passe-t-il si la connexion internet coupe ?
Le client desktop synchronise vos fichiers en local. Si internet coupe, vous pouvez continuer à travailler sur vos documents. De plus, l'IA locale "Little Abraham" continue de fonctionner sans accès réseau puisque l'inférence tourne sur votre propre machine.
Comment le partenaire MSP encaisse-t-il ses commissions ?
Le portail MSP intègre Stripe Connect. Une fois votre IBAN renseigné, les commissions de 15% sont automatiquement calculées à chaque paiement client et transférées sur votre compte bancaire, sans intervention manuelle.
Quelles sont les configurations matérielles requises pour l'IA Locale ?
"Little Abraham" est optimisé pour les processeurs modernes (Apple Silicon M1/M2/M3 ou Intel/AMD récents avec 16 Go de RAM). L'inférence s'adapte automatiquement à la puissance graphique (GPU/NPU) disponible sur le poste.
Peut-on utiliser nos propres serveurs (On-Premise total) ?
Absolument. Kuro Suite est conçu pour être déployé via un script d'installation unique (`install.sh`) sur n'importe quel serveur Debian/Ubuntu, que ce soit chez un hébergeur cloud européen (OVH, Hetzner, Scaleway) ou dans vos propres salles serveurs (On-Premise).
